# 🚀 45 Days Web Development Challenge  Welcome to my **45 Days Web Development Challenge** repository! This repository documents my journey of learning web development from scratch through **daily coding, projects, and consistent practice**.  The purpose of this challenge is to build a strong foundation in frontend development, improve problem-solving skills, and create a portfolio of projects by the end of 45 days.  ## 🎯 Challenge Objectives - Code every day for 45 consecutive days. - Master HTML, CSS, and JavaScript fundamentals. - Build real-world mini projects. - Improve coding consistency and discipline. - Prepare for advanced frontend frameworks and full-stack development.  ## 📅 Challenge Roadmap  ### Phase 1 – HTML (Days 1–15) - HTML Basics - Document Structure - Headings & Paragraphs - Text Formatting - Lists - Links - Images - Tables - Forms - Audio & Video - Semantic HTML - Resume Website - Admission Form - Portfolio Layout - Mini HTML Projects  ### Phase 2 – CSS (Days 16–30) - CSS Basics - Colors & Units - Fonts & Typography - Box Model - Display Properties - Positioning - Flexbox - CSS Grid - Responsive Design - Animations & Transitions - Media Queries - Navigation Bars - Cards - Landing Pages - Complete Responsive Projects  ### Phase 3 – JavaScript (Days 31–45) - JavaScript Basics - Variables & Data Types - Operators - Conditions - Loops - Functions - Arrays & Objects - DOM Manipulation - Events - Forms Validation - Local Storage - API Basics - Calculator Project - To-Do List Project - Final Interactive Website  ## 📂 Repository Structure ``` Day-01/ Day-02/ Day-03/ ... Day-45/ ```  Each folder contains the source code and practice files completed on that day.  ## 🛠️ Technologies Used - HTML5 - CSS3 - JavaScript (ES6+) - Visual Studio Code - Git & GitHub  ## 📈 Goals - ✔️ Complete all 45 days without skipping. - ✔️ Build multiple mini projects. - ✔️ Strengthen frontend development skills. - ✔️ Create a professional GitHub portfolio. - ✔️ Build a solid foundation for React and Full-Stack Development.  ## 🌱 What I'll Learn - Writing clean and semantic HTML - Styling responsive websites with CSS - Adding interactivity using JavaScript - Debugging and problem-solving - Git and GitHub workflow - Project organization and best practices  ## 📌 Why This Challenge? Consistency beats intensity. This challenge is my commitment to improving one day at a time through hands-on practice and project-based learning.  ## 🤝 Connect With Me If you're also learning web development, feel free to explore this repository, share feedback, or follow my progress.  ⭐ If you find this repository helpful or inspiring, consider giving it a star!
