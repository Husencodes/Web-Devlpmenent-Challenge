CSS Box Model ⭐ Every HTML element can be understood as: **Content → Padding → Border → Margin** ```css .box { width: 200px; padding: 20px; border: 2px solid black; margin: 30px; } ``` ### Remember: - **Content** → actual text/image - **Padding** → space inside the element - **Border** → boundary - **Margin** → space outside the element ### `box-sizing` ```css * { box-sizing: border-box; } ``` This makes width/height calculations easier because padding and border are included in the declared size. --- # 6. Display Property ⭐ ### Block ```css div { display: block; } ``` Takes the available width and normally starts on a new line. ### Inline ```css span { display: inline; } ``` Usually occupies only the required content width. ### Inline-block ```css span { display: inline-block; } ``` Allows an inline-level element to have width, height, padding, etc. ### None ```css .box { display: none; } ``` The element is removed from the layout. --- # 9. Position Property ⭐ ```css position: static; position: relative; position: absolute; position: fixed; position: sticky; ``` ### Relative ```css .box { position: relative; top: 20px; } ``` ### Absolute ```css .child { position: absolute; top: 0; right: 0; } ``` An absolutely positioned element is positioned relative to an appropriate positioned ancestor. ### Fixed ```css button { position: fixed; bottom: 20px; right: 20px; } ``` Remains fixed relative to the viewport. ### Sticky ```css header { position: sticky; top: 0; } ``` Useful for sticky navigation. --- # 10. Flexbox ⭐⭐⭐ One of the most important CSS topics. ```css .container { display: flex; } ``` Important properties: ```css flex-direction justify-content align-items align-content flex-wrap gap ``` Example: ```css .container { display: flex; justify-content: center; align-items: center; gap: 20px; } ``` ### Main Axis vs Cross Axis ```text justify-content → Main Axis align-items → Cross Axis ``` Common values: ```css justify-content: center; justify-content: space-between; justify-content: space-around; justify-content: space-evenly; align-items: center; ``` --- # 11. CSS Grid ⭐⭐⭐ Grid is useful for two-dimensional layouts. ```css .container { display: grid; grid-template-columns: repeat(3, 1fr); gap: 20px; } ``` Example: ```css .container { display: grid; grid-template-columns: 200px 1fr 200px; } ``` Important properties: - `grid-template-columns` - `grid-template-rows` - `gap` - `grid-column` - `grid-row` --- # 12.
